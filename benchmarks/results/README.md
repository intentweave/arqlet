# Benchmark and comparison results

Records before 2026-11-09 were made under the working name Layerweave: they name the engine `layerweave` and the
crates `layerweave-*`. They are kept as recorded; absolute checkout paths were made relative.

Raw results are JSON Lines (one run per line). Each line records its environment (CPU, OS, Rust or
Node version) and the git revision with a dirty flag. Compare only results from the same machine.
Several runs were made with uncommitted changes (`gitDirty: true`), so they document a state,
not a clean baseline.
