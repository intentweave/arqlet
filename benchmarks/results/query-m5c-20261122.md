# A query-only WASM module (ADR 0021, M5c): size against the engine's

Machine: Apple M3 (macOS), rustc 1.99.0. Revision: 606b65a plus the M5c change (the crates `arqlet-query-json` and
`arqlet-query-wasm`). Measured 2026-11-22. Raw bytes of the `.wasm` file; gzip is `gzip -9`.

`cargo build -p <crate> --target wasm32-unknown-unknown --profile <profile> --locked [--features query]`. The profile
`wasm-size` is the one of the npm artifact; `release` is the one of the playground.

| Profile | Module | Raw | gzip | Share of the engine with `query` |
|---|---|---|---|---|
| `wasm-size` | `arqlet-query-wasm` (query only) | 1 019 105 B | 328 063 B | 14.3 % raw, 17.8 % gzip |
| `wasm-size` | `arqlet-wasm` without `query` | 6 345 499 B | 1 594 359 B | |
| `wasm-size` | `arqlet-wasm` with `query` | 7 121 627 B | 1 838 647 B | 100 % |
| `release` | `arqlet-query-wasm` (query only) | 1 668 972 B | 464 640 B | 12.2 % raw, 15.2 % gzip |
| `release` | `arqlet-wasm` without `query` | 12 257 752 B | 2 679 695 B | |
| `release` | `arqlet-wasm` with `query` | 13 655 889 B | 3 049 893 B | 100 % |

A host that wants queries and no layout loads about one seventh of the engine's bytes (a sixth of its gzip).

## What the module is checked against

`tools/query-wasm.test.mjs` loads the built module in Node and runs every supported case of `examples/cypher/` through
`lw_alloc`, `lw_run` and `lw_free`: all 40 give the rows of the independent Python oracle. The same test checks that errors
come back as answers with their class and that a failed `load` keeps what was loaded. The module's own unit tests run
natively (`cargo test -p arqlet-query-wasm`).

## Not measured

How much of the module is `arqlet-model` (its layout and scene types come along with the graph types) and how much is
decypher; so the size a split-off graph-only crate (ADR 0021 item 12) would save is not known. The time to `load` a graph
is not measured either.
