# Organic placement after the scale and start correction (second comparison)

Machine: Apple M3, 8 logical CPUs, 16 GiB, macOS 26.0. Revision: the organic-straight branch (after cbc3880). Program: `crates/runtime/examples/organic_compare.rs`. Default options, one thread, one run per cell. Times are indicative.

What changed against the first comparison (`organic-20261024.md`): the target length is the mean node size plus the gap (it was a unit length); the start is pivot MDS on the squared distances instead of two distance coordinates; the stress stage reports its stress before and after and its iteration count. Stage behaviour, measured on path (8), star (9), cycle (10) and a star with wide boxes: the path becomes straight with stress 0 (the separation keeps its order); the star keeps two dimensions (main 260, minor 260 after stress); the cycle keeps its ring. The separation stage enlarges the main extent by about 20 percent on the star and by about 30 percent on the path.

Setup: every direction set to `auto` (a comparison variant), organic with straight edges, organic with orthogonal routing, and the hierarchical plain layout with orthogonal routing. State-tcp and network-vlan have parallel or antiparallel pairs, so straight routing refuses them.

## Refused by design

- state-tcp.json, organic+straight: straight routing does not draw parallel edges between LISTEN and CLOSED yet
- network-vlan.json, organic+straight: straight routing does not draw parallel edges between core-a and core-b yet
- workflow-dag.json, organic+straight: straight routing does not draw parallel edges between task:5:0 and task:4:2 yet

## Reading

1. The scale correction changed the organic results substantially. On state-tcp the organic drawing with orthogonal routing has 1 crossing and 2 shared pairs (the first comparison: 7 and 38); on network-vlan it has 31 crossings and 19 shared pairs (49 and 73), and it is shorter than the hierarchical layout (14.8 k against 29.2 k).
2. The hierarchical layout is still better on org-chart crossings (57 against 69) and on workflow-dag (329 against 698). Organic with orthogonal routing on org-chart has far fewer shared pairs (9 against 69).
3. Straight routing on org-chart still reports 318 routing issues: segments pass through foreign nodes. The stage analysis was run on path, star and cycle only; which stage causes the issues on org-chart is not yet analysed, and placement repair is open.
4. The asymmetric tree and the mixed drawing have no straight-routing issues.
