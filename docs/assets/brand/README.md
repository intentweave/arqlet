# Arqlet brand assets

**Arqlet — Interactive graphs, continuously arranged.**

Explore hierarchies, flows, and graphs in one connected view.

- [Cover](arqlet-cover.svg): dark title image showing connected hierarchy, flow and graph regions; used by the project README.
- [Icon](arqlet-icon.svg): mint A contour with a lavender crossbar and graph junctions on a transparent background.
- [Wordmark](arqlet-wordmark.svg): transparent, light lettering intended for dark backgrounds.

Palette: dark blue `#101b2a`, mint `#80dfc0`, lavender `#a7b7ff`.
The SVGs are editable source assets. They contain no external images or scripts. Text uses system-font fallbacks; letter shapes can vary between systems.

These assets are distributed under the repository's license (MIT OR Apache-2.0).
The cover illustrates the intended mixed-layout capability, not an engine-generated layout or a feature-completeness claim.
Technical package and crate identifiers are unchanged by this visual branding update.
